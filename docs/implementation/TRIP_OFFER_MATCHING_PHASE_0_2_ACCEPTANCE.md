## 執行取捨

1. Windows 無法執行技能的 Bash 記錄工具，使用同一工作樹的明確進度檔；沒有改 Git 分支、提交或清理既有變更。
2. Corepack 嘗試下載 registry 套件受阻，改用已安裝 Node 與本機套件入口執行同等測試／型別檢查／建置，沒有升級或安裝依賴。
3. Windows 一般執行環境不能建立測試用暫存 Git／hard-link 或 Next junction；經本機執行權限審查後重跑成功。另一項 symlink 測試明確略過，仍待 Linux CI；沒有把略過算成通過。
4. 原 app source packer 的安全邊界保留；另提供保留倉庫相對位置的 preview 補充封包。原 app zip 單獨不包含外層本機 server；重建預覽需補充封包及正常安裝依賴。
5. 私人已保存來源讀取仍核對版本和用途；60 秒來源新鮮度在配對及寫入前核對，並只在已同意後作唯讀刷新。私人舊 brief 可讀不代表遠端當下可用。
6. 原 editor 的摘要、標題、城市及日標題沒有各自的來源欄位；混合授權內容時採保守綁定。撤權後這些顯示欄位可能暫時隱藏，即使部分是作者自寫；原版本 bytes、獨立原創站點和私人筆記不會刪除。`trip_day` 是本機契約補充，N 的 schema 審閱須納入，這次沒有建立遷移。
