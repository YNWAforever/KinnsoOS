## Actual reused code

`imageMapPinToFeature` and `imageMapPinsToGeoJson` retain the upstream function bodies. The selected type declarations are retained/adapted. Svelte `$lib/types` and `FullMap.svelte` type imports are replaced by local `ImageSource` and `FullMapFeatureCollection` definitions. Unneeded collection, fetching, validation, merge and navigation utilities are omitted. An attribution/modification header was added.

`TripMap.tsx` imports `imageMapPinsToGeoJson`. Its `stopsToGeoJson` adapter filters invalid or absent coordinates and supplies normalized IDs, safe image references, coordinates and parent labels. The resulting GeoJSON drives displayed markers, center/zoom, selected-stop focus, labels, click-to-select IDs and location counts. The converter therefore participates in active runtime behavior; this is not merely visual inspiration or unused vendored code.

No AdventureLog account, API, Django database, Svelte application, authorization scheme or server was copied. Kinnso's normalized demo model remains separate and ready for a canonical service contract.
